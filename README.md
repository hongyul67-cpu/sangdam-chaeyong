# 상담·행정 채용공고 (sangdam-chaeyong)

**청소년상담사 자격으로 지원할 수 있는 상담직·행정직 공고**를
서울·경기·인천에서 **월요일·목요일 아침에 자동으로** 모아 한 장짜리 웹페이지로 정리합니다.

**👉 최신 공고 보기 : https://hongyul67-cpu.github.io/sangdam-chaeyong/**

---

## 이 자료를 보는 분께

- 맨 위 **⭐ 청소년상담사 자격이 적힌 공고** 가 가장 먼저 볼 표입니다
- **`한눈에 보기`** 표에서 기관명을 누르면 아래 상세로 내려갑니다
- **🖨 인쇄 / PDF로 저장**, **⬇ 엑셀로 받기** 로 뽑아 보실 수 있습니다
- 폰으로 봐도 됩니다 (좁은 화면에서는 덜 중요한 열이 숨습니다)

> ⚠️ **지원 전에 반드시 원문 공고를 확인하세요.**
> 이 표는 잡알리오·워크넷의 요약을 자동으로 정리한 것이라
> 자격요건·마감일이 실제 공고와 다를 수 있습니다.
> **⭐ 는 공고 글자에 '청소년상담사'가 들어 있다는 표시일 뿐**이며,
> 필수 자격인지 우대인지는 원문에서 확인해야 합니다.

## 언제 갱신되나

| | |
|---|---|
| 주기 | **월요일 · 목요일 오전 8:50** (한국시간) — 3~4일에 한 번 |
| 실행 | GitHub Actions (내 컴퓨터가 꺼져 있어도 돕니다) |
| 손으로 돌리기 | `Actions` 탭 → `상담·행정 공고 수집` → `Run workflow` |

깃허브 예약은 매시 00분이 가장 붐벼 수십 분 밀립니다.
그래서 9시가 아니라 **8:50** 에 걸어 두었습니다.

워크플로에 **`TZ: Asia/Seoul`** 이 들어 있어야 화면의 '마지막 갱신'과
로그·날짜가 한국시간으로 찍힙니다. 서버는 UTC 로 돕니다.

## 어디에서 긁어오나

| 곳 | 무엇을 담나 | 인증키 |
|---|---|---|
| **잡알리오** (공공데이터포털) | 공공기관 공고. 한국청소년상담복지개발원·청소년활동진흥원 등 | `ALIO_API_KEY` |
| **워크넷** (고용24 OPEN-API) | 시·군·구 청소년상담복지센터, 꿈드림, 건강가정지원센터 등 | `WORK_API_KEY` |

둘 다 **저장소 시크릿**에 넣습니다 (`Settings` → `Secrets and variables` → `Actions`).
한쪽 키만 있어도 그쪽만 모아서 돌아갑니다.

**잡알리오 키** — [공공데이터포털 15125273](https://www.data.go.kr/data/15125273/openapi.do) 에서
활용신청(자동승인) → 마이페이지에서 **일반 인증키(Decoding)** 복사.

**워크넷 키** — 2026년에 **워크넷 OPEN-API가 「고용24 OPEN-API」로 통합**되었습니다.
공공데이터포털의 `3038225` 는 **LINK 형이라 거기서는 키가 안 나옵니다.**
[고용24](https://www.work24.go.kr/) 에서 받아야 합니다.

1. 고용24 **기업회원**으로 가입 — *OPEN-API는 기업회원 전용입니다*
2. 로그인 → `고객센터` → `OPEN-API` → **`서비스 소개 및 신청`**
3. **`채용정보`** 를 골라 인증키 신청
4. **담당자 심사** 후 발급 (자동승인이 아닙니다 — 며칠 걸릴 수 있습니다)
5. `신청현황` 메뉴에서 발급된 키 확인

> ⚠️ 워크넷 API 는 **http 로만** 부릅니다. https 로는 못 받습니다 —
> 서버 인증서에 Authority Key Identifier 가 빠져 있어 요즘 OpenSSL 이 검증을 거부합니다.
> (2026-09-17 에 이 노트북과 curl 양쪽에서 확인)

> 로그(`data/log.txt`)는 공개 저장소에 그대로 올라갑니다.
> 그래서 **인증키가 붙은 주소는 어떤 경우에도 로그에 찍지 않습니다.**

## 무엇을 담고 무엇을 버리나

**담는 것**

- **상담 · 청소년 · 복지 · 교육** 중 하나라도 걸리는 공고
- **행정직**은 '어디의 행정인지'를 봅니다 —
  기관명·제목에 청소년·상담·복지·가족·교육·학교 같은 말이 있을 때만 담습니다

**버리는 것**

- 근무지가 서울·경기·인천이 아닌 것
- 미화·경비·조리·운전·간호 등 상담사 자리가 아닌 것
- 한국전력 사무직처럼 **기관이 무관한 일반 사무직**

**버리지 않고 표시만 하는 것**

- 기간제·시간제 → `고용형태` 칸에 그대로 나옵니다
- 육아휴직 대체인력 → 카드에 빨간 글씨로 `대체인력(육아휴직 등) 채용`

## 설정 바꾸기 (`collect.py` 맨 위)

```python
REGIONS_ALIO = "R3010,R3017,R3011"   # 서울 R3010 · 경기 R3017 · 인천 R3011
REGIONS_WORK = "11000|41000|28000"   # 워크넷은 코드 체계가 다릅니다
TAG_KEYWORDS = { "상담": [...], "청소년": [...], ... }   # 이름표
LICENSE_STAR = ["청소년상담사", "청소년 상담사"]          # ⭐ 를 붙이는 낱말
SAMU_NEEDS_CONTEXT = [...]           # 행정직을 담을 기관 낱말
SKIP_WORDS = [...]                   # 제목에 있으면 버리는 낱말
```

**낱말을 넣고 빼는 것만으로 검색 범위가 바뀝니다.**
넓히면 엉뚱한 공고가 걸리니, 바꾼 뒤 한 번 돌려 보고 `data/log.txt` 의
'버린 이유' 줄을 확인하세요.

```
docs/                     ← 깃허브 Pages 가 서비스하는 폴더
 ├ index.html             늘 최신 — 지금 지원 가능한 공고
 ├ 2026-09-17.html        회차별 신규 공고 (신규 0건인 날은 만들지 않음)
 ├ archive.html           지난 회차 목록
 └ files/<날짜>/*.xlsx    엑셀 (가로 방향·너비 1페이지 인쇄 설정)

data/                     실행 상태 (사람이 볼 일 없음)
 ├ state_seen.json        이미 본 공고 번호 (NEW 표시에 씀)
 ├ history.json           누적 이력
 ├ last_run.txt           마지막 실행 기록
 └ log.txt                실행 로그

collect.py                프로그램 본체
.github/workflows/        월·목 자동 실행 설정
```

## 알아둘 것

- 화면의 **D-day 는 브라우저가 열어 보는 날 기준으로 다시 계산**합니다.
  사흘 전에 만든 페이지라도 이미 마감된 공고는 회색으로 죽습니다.
- **신규 0건인 날은 회차 리포트를 만들지 않습니다.** 빈 껍데기가 목록을 채우기 때문입니다.
- 워크넷은 검색어를 주지 않으면 수도권 공고가 수만 건이라,
  `WORK_KEYWORDS` 의 낱말별로 나눠 부르고 구인인증번호로 합칩니다.
- 매번 `data/last_run.txt` 를 갱신해 커밋합니다.
  깃허브가 **60일간 활동 없는 저장소의 예약 작업을 꺼 버리기** 때문입니다.
