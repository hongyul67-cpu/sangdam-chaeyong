# 상담·행정 채용공고 (sangdam-chaeyong)

**청소년상담사 자격으로 지원할 수 있는 상담직·행정직 공고**를
**노원 기준 출퇴근권**(서울 전역 + 경기 북동부)에서
**월요일·목요일 아침에 자동으로** 모아 한 장짜리 웹페이지로 정리합니다.

**👉 최신 공고 보기 : https://hongyul67-cpu.github.io/sangdam-chaeyong/**

---

## 이 자료를 보는 분께

- 맨 위 **⭐ 청소년상담사 자격이 적힌 공고** 가 가장 먼저 볼 표입니다
- **근무지** 칸의 초록 `가까움` · 남색 `서울권` · 회색 `먼 편` 이 노원에서의 거리입니다
  (가까운 곳이 위로 올라옵니다)
- **`한눈에 보기`** 표에서 기관명을 누르면 아래 상세로 내려갑니다
- **🖨 인쇄 / PDF로 저장**, **⬇ 엑셀로 받기** 로 뽑아 보실 수 있습니다
- 폰으로 봐도 됩니다 (좁은 화면에서는 덜 중요한 열이 숨습니다)

> ⚠️ **지원 전에 반드시 원문 공고를 확인하세요.**
> 이 표는 잡알리오·워크넷의 요약을 자동으로 정리한 것이라
> 자격요건·마감일이 실제 공고와 다를 수 있습니다.
> **⭐ 는 공고 글자에 '청소년상담사'가 들어 있다는 표시일 뿐**이며,
> 필수 자격인지 우대인지는 원문에서 확인해야 합니다.

## 언제 갱신되나

| | |
|---|---|
| 주기 | **월요일 · 목요일 오전 8:50** (한국시간) — 3~4일에 한 번 |
| 실행 | GitHub Actions (내 컴퓨터가 꺼져 있어도 돕니다) |
| 손으로 돌리기 | `Actions` 탭 → `상담·행정 공고 수집` → `Run workflow` |

깃허브 예약은 매시 00분이 가장 붐벼 수십 분 밀립니다.
그래서 9시가 아니라 **8:50** 에 걸어 두었습니다.

워크플로에 **`TZ: Asia/Seoul`** 이 들어 있어야 화면의 '마지막 갱신'과
로그·날짜가 한국시간으로 찍힙니다. 서버는 UTC 로 돕니다.

## 어디에서 긁어오나

| 곳 | 무엇을 담나 | 인증키 |
|---|---|---|
| **잡알리오** (공공데이터포털) | 공공기관 공고. 한국청소년상담복지개발원·법무보호복지공단 등 | `ALIO_API_KEY` |
| **복지넷** (한국사회복지협의회) | **시·군·구 청소년상담복지센터·꿈드림·가정폭력상담소·아동보호전문기관** | 없음 |
| 워크넷 (고용24) | *아직 안 씀 — 인증키가 기업회원 전용이라 못 받았습니다* | `WORK_API_KEY` |

**잡알리오 키** — [공공데이터포털 15125273](https://www.data.go.kr/data/15125273/openapi.do) 에서
활용신청(개발단계 자동승인) → `마이페이지` → `데이터활용` → `Open API` → `개발계정` 에서
**일반 인증키(Decoding)** 복사 → 저장소 시크릿 `ALIO_API_KEY` 에 넣습니다.
내 노트북에서 시험 삼아 돌릴 때는 이 폴더에 `.env` 를 만들어 `ALIO_API_KEY=키` 한 줄을 적습니다
(`.gitignore` 에 걸려 있어 저장소에 올라가지 않습니다).

**복지넷은 인증키가 없습니다.** 검색 화면을 그대로 POST 로 부릅니다.
남의 집이니 조심해서 씁니다 —

- `robots.txt` 가 `/*?`(쿼리가 붙은 주소)를 막고 있습니다.
  목록은 POST 라 해당이 없지만, **상세 페이지(`?ID=…`)는 긁지 않고 링크만 겁니다.**
- 요청 사이를 1초 쉬고, 주 2회만 돕니다. 지역 2곳 × 낱말 7가지 = 14번 남짓입니다.
- 화면이 바뀌면 파싱이 깨집니다. 그때는 `bokji_parse()` 의 `td` 순서를 다시 맞춰야 합니다.

**워크넷(고용24)** — OPEN-API가 **기업회원 전용**이라 개인은 인증키를 받을 수 없습니다.
그래서 지금은 복지넷으로 대신합니다. 나중에 키가 생기면 시크릿 `WORK_API_KEY` 만 넣으면
다음 실행부터 저절로 합쳐집니다.

> 로그(`data/log.txt`)는 공개 저장소에 그대로 올라갑니다.
> 그래서 **인증키가 붙은 주소는 어떤 경우에도 로그에 찍지 않습니다.**

### 인증서 검증에 대해

학교 망에는 TLS 를 들여다보는 검사 장비가 있어서, 이 노트북에서는 파이썬이
**구글조차 검증하지 못합니다**(`self-signed certificate`). 깃허브 서버에는 그런 장비가 없어
정상으로 검증됩니다. 그래서 `_urlopen()` 은 **먼저 제대로 검증해 보고, 막히는 기계에서만**
검증을 접고 로그에 남깁니다. 읽기만 하고 개인정보를 보내지 않아 이 정도는 감수합니다.

## 무엇을 담고 무엇을 버리나

공고 **제목과 기관명만** 봅니다. 관문은 셋입니다.

1. 공고에 **'청소년상담사'** 가 적혀 있으면 → 무조건 담고 ⭐ 를 붙입니다
2. **제목**이 상담·청소년·심리·꿈드림·학교밖… 이면 → 담습니다
3. **기관명**이 청소년·상담·가족·아동·심리·복지관·학교… 이면 → 담습니다

> ⚠️ **자격요건 전문을 훑으면 안 됩니다.** 공공기관 공고문 자격요건에는
> '장애인복지법·국가유공자·행정' 같은 상투 문구가 반드시 들어가서,
> 실제로 **87건 중 82건이 통과**해 한국도로공사·한국전력까지 잡혔습니다.
> 자격 전문은 ⭐ 판정에만 씁니다.

**버리는 것**

- **출퇴근 권역 밖** (인천·충청 등 — `ZONES` 어디에도 안 걸리는 곳)
- 미화·경비·조리·운전·간호·요양보호사·생활지도원 등 상담사 자리가 아닌 것
- 한국전력 사무직처럼 기관도 직무도 무관한 자리

**합치는 것**

- 같은 자리가 '재공고'·'끌어올림'으로 여러 번 올라오면 **한 줄로 합칩니다.**
  버리지 않고 합치는 이유는, 한쪽은 `서울특별시` 인데 다른 쪽은 `서울특별시 노원구` 처럼
  **한쪽에만 있는 정보**가 있기 때문입니다.

**버리지 않고 표시만 하는 것**

- 기간제·계약직 → `고용형태` 칸에 그대로 나옵니다
- 육아휴직 대체인력 → 카드에 빨간 글씨로 `대체인력(육아휴직 등) 채용`

## 설정 바꾸기 (`collect.py` 맨 위)

```python
ZONES = [...]                        # 노원에서 가까운 순. 여기 없는 지역은 버립니다
REGIONS_ALIO = "R3010,R3017"         # 서울 R3010 · 경기 R3017
BOKJI_REGIONS = [("11000","서울"), ("41000","경기")]
BOKJI_KEYWORDS = ["상담","청소년","꿈드림","심리","학교밖","동반자"]
JOB_WORDS = [...]                    # 제목이 이러면 담습니다
ORG_WORDS = [...]                    # 기관명이 이러면 담습니다
LICENSE_STAR = ["청소년상담사", ...]   # ⭐ 를 붙이는 낱말
SKIP_WORDS = [...]                   # 제목에 있으면 버리는 낱말
```

**낱말을 넣고 빼는 것만으로 검색 범위가 바뀝니다.**
넓히면 엉뚱한 공고가 걸리니, 바꾼 뒤 한 번 돌려 보고 `data/log.txt` 의
'버린 이유' 줄을 확인하세요.

## 폴더 구조

```
docs/                     ← 깃허브 Pages 가 서비스하는 폴더
 ├ index.html             늘 최신 — 지금 지원 가능한 공고
 ├ 2026-09-17.html        회차별 신규 공고 (신규 0건인 날은 만들지 않음)
 ├ archive.html           지난 회차 목록
 └ files/<날짜>/*.xlsx    엑셀 (가로 방향·너비 1페이지 인쇄 설정)

data/                     실행 상태 (사람이 볼 일 없음)
 ├ state_seen.json        이미 본 공고 번호 (NEW 표시에 씀)
 ├ history.json           누적 이력
 ├ last_run.txt           마지막 실행 기록
 └ log.txt                실행 로그

collect.py                프로그램 본체
.github/workflows/        월·목 자동 실행 설정
```

## 알아둘 것

- 화면의 **D-day 는 브라우저가 열어 보는 날 기준으로 다시 계산**합니다.
  사흘 전에 만든 페이지라도 이미 마감된 공고는 회색으로 죽습니다.
- **신규 0건인 날은 회차 리포트를 만들지 않습니다.** 빈 껍데기가 목록을 채우기 때문입니다.
- 워크넷은 검색어를 주지 않으면 수도권 공고가 수만 건이라,
  `WORK_KEYWORDS` 의 낱말별로 나눠 부르고 구인인증번호로 합칩니다.
- 매번 `data/last_run.txt` 를 갱신해 커밋합니다.
  깃허브가 **60일간 활동 없는 저장소의 예약 작업을 꺼 버리기** 때문입니다.
